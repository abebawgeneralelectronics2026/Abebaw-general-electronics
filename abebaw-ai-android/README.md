# ABEB AW AI ASSISTANT

Your Personal Intelligent Assistant.

## Project Goal
Build an Android AI assistant that can help the user perform phone tasks with explicit permission.

## Safety Rules
1. Ask permission before starting a task.
2. Ask for a second confirmation before deleting files or changing important settings.
3. Never perform an unapproved action.
4. Report what was completed.

Initial project setup.
